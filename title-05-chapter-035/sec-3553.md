# § 3553. Criminal penalties [For application of this section, see 85 Del. Laws, c. 339, § 2].
(a) It is unlawful to knowingly issue a payment stablecoin without a license required by this chapter. Violation of this subsection is a class F felony.
(b) It is unlawful to knowingly make a material misrepresentation in an application for a license under this chapter. Violation of this subsection is a class F felony.
(c) It is unlawful to knowingly submit a false certification of any report or disclosure required under this chapter. Violation of this subsection is a class F felony.
